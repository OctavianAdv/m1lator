# m1lator

A personal mod kit for BlueStacks 4.220 (`bgp64`). It covers custom themes, performance and rendering tuning, and compatibility tweaks.

This repo holds only our own work: themes, registry presets, patch scripts and docs.
BlueStacks binaries and decompiled source are git-ignored and are never committed.

See [docs/ROADMAP.md](docs/ROADMAP.md).
